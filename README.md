# 모두의테니스클럽 MTC · v19 클럽관리

사이트: https://cojumkr.github.io/moduetennis/

## v19 추가 기능
- 회원별 **+1 / -1** 코인 수동 조정 (사유 입력, 날짜별 이력, 조정 취소)
- 신규 회원 초기 코인 **+1 버튼 3회**로 수동 지급 가능
- **게스트 → 정회원 전환** (과거 게스트 경기 기록 유지, 새 회원 ID 생성, NTRP 승계)
- 정회원 전환 시 게스트 잔여 코인은 회수 처리, 신규 회원 코인은 0개에서 시작
- 기존 출석, 자동·수동 대진, 승패, 코인 대출, 출석 코인, 백업 기능 유지

## 배포 방법
GitHub 저장소 최상위의 `index.html`을 이 파일로 **교체하고 커밋**합니다. GitHub Pages 배포 완료 후 강력 새로고침하세요. `README.md`도 교체할 수 있습니다.

## 기록 보존 주의
기존 Firebase `clubs/mtc`를 사용합니다. 새 기능은 기존 회원·경기 데이터를 초기화하지 않습니다. 업데이트 전에 Firestore 원본 백업을 권장합니다. 실서비스 Firebase 동시 접속 및 배포 검증은 수행하지 않았습니다.

## 운영 참고
수동 코인 지급은 출석 보너스나 대출과 별도입니다. 중복 지급을 주의하세요. 정회원 전환 시 이전 게스트 계정의 과거 경기 결과는 회원 계정으로 소급 합산하지 않습니다. 익명 편집이므로 사이트 주소를 아는 사람은 데이터를 수정할 수 있습니다.
