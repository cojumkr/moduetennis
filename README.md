# MTC v22 — 과거 경기 점수 수정

기존 Firebase `clubs/mtc` 기록을 유지하며 완료된 경기의 게임 스코어를 수정하는 기능을 추가했습니다.

- 날짜별 완료 경기와 전체 코인 기록의 승패 기록에서 **점수 수정** 클릭
- A팀·B팀 점수 입력 후 저장
- 기존 승리팀을 바꾸지 않는 점수 수정만 허용
- 승패·코인 정산은 유지, 실력 레이팅은 전체 경기 순서에 따라 다시 계산
- 각 경기 `scoreEdits` 배열에 이전 점수, 새 점수, 수정 시각 기록
- 기존 스코어 미입력 경기에도 추후 점수 입력 가능

배포 전 Firebase 데이터를 백업하세요. 실제 Firebase 환경에서의 동작은 검증되지 않았습니다.
