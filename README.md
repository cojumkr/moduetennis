MTC v103 — 기상청 API 인증키 자동 적용

- 발급받은 기상청 인증키를 기본값으로 내장하여 재입력할 필요가 없습니다.
- 기존 v102 기능과 출석/경기/코인/Firebase 저장 구조는 그대로 유지합니다.
- 날씨 영역의 ‘⚙ 키 변경’은 선택 기능이며, 비워두면 기본 내장 키를 사용합니다.
- 중요: 이 버전은 HTML 파일에 인증키가 포함되어 있습니다. 공개 웹사이트에 배포하면 방문자가 키를 확인할 수 있습니다. 안전한 운영을 위해서는 서버 측 프록시로 키를 옮겨야 합니다.
- 실제 API 호출/CORS 동작은 배포 환경에서 확인해야 합니다.
