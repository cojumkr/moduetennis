# MTC v21 — 스코어·실력 레이팅

- 경기 결과 확정 시 양 팀 게임 스코어 입력 필수 (예: 6:3). 승리팀과 점수 일치 확인.
- 기존 코인 정산은 그대로 유지.
- 실력 레이팅 메뉴: 전원 5.000 출발, Elo K=32, 팀 평균 실력에 따른 승패 변동, 점수 차이에 따른 0.75~1.25 가중치.
- 단식/복식 공통, 복식은 팀 평균 레이팅으로 계산하며 팀원 각각 동일 변동.
- 과거 승패 기록은 스코어 미입력 상태로 보존하고 가중치 1.0으로 레이팅에 반영.
- 모든 레이팅은 저장된 경기 기록에서 날짜/생성시각순으로 재계산되므로 과거 경기 추가나 경기 취소 시 전체 점수가 다시 산출됨.
- 공식 NTRP 수치와 구분되는 MTC 내부 레이팅. 기존 NTRP 대진 설정은 유지.
- 기존 Firebase 프로젝트 및 Firestore 저장 경로 유지. 업로드 전에 Firebase 데이터 백업 필수.
