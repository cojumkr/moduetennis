# MTC v103 — 코인 대출 상환 / 리그전 개별 경기 선수 교체

- 코인 대출 탭에서 **대출 상환**: 보유 코인과 대출 잔액을 동일 수량 차감, `loan_repayment` 거래 기록 저장. 잔액·보유량 초과 상환 금지.
- 월례 리그전의 **미진행 경기**에 `이 경기 선수 교체` 버튼 추가. A/B팀 선수 위치 선택 후 교체할 회원 지정.
- 같은 경기 중복 선수 배치 차단. 기존 결과가 연결된 경기는 교체 불가(먼저 결과 취소).
- 선수 교체는 다른 경기, 출석 신청, 코인 잔액을 수정하지 않음. 변경 이력은 해당 월례대회 `edits`에 보관.
- 예: 6번 경기 김인호 → 백경식, 9번 경기 김혜성 → 박대웅. 실제 데이터는 사용자가 버튼으로 선택하여 변경해야 함.
- 월례대회 포스터는 최신 경기 대진을 읽으므로 교체 후 재출력 필요.
- 기존 지정팀 토너먼트, 리그전 생성 및 취소 기능 유지.

주의: Firebase 실사용 테스트는 별도로 필요. 배포 전 전체 기록 백업을 권장합니다.
