# 🎾 모두의테니스클럽 (MTC)

### MTC Tennis Club | 코인 리그 운영 시스템

모두의테니스클럽(MTC)은 경기도 파주시 법원읍에서 활동하는 테니스 동호회입니다.

본 사이트는 클럽 회원들의 출석 관리, 자동 대진 편성, 경기 결과 기록 및 코인 리그 운영을 위해 제작되었습니다.

**🌐 [MTC 코인 리그 사이트 바로가기](https://cojumkr.github.io/moduetennis/)**

---

## 1. 주요 기능

### 👥 회원 및 게스트 관리
- 클럽 회원 명단 및 활동 상태 확인
- 회원별 NTRP 실력 등급 설정
- 게스트 현장 등록 및 NTRP 입력
- 회원과 게스트의 출석·퇴장 관리

### 📅 출석 및 경기 기록
- 날짜별 클럽데이 출석 관리
- 경기 중간 참여 및 퇴장 반영
- 날짜별 대진과 경기 결과 기록
- 당일 회원별 경기 참여 횟수 확인

### 🎾 자동 대진 편성
- 테니스 코트 2면 기준 복식 대진 자동 생성
- 회원별 당일 경기 참여 횟수 고려
- NTRP를 활용한 실력 균형 편성
- 동일 파트너 및 상대와의 반복 경기 최소화

### 🪙 코인 리그
- 반기별 시즌 운영 (상반기 / 하반기)
- 시즌 최초 참여 시 기본 코인 3개 지급
- 단식 승리 +1 / 패배 -1
- 복식 승리팀 각 +1 / 패배팀 각 -1
- 코인 부족 시 클럽 대출 관리
- 보유 코인에서 누적 대출을 차감한 순위 관리
- 게스트 퇴장 시 잔여 코인 회수

### 🏆 시즌 순위
- 회원별 코인 현황 확인
- 반기별 누적 순위 확인
- 회원과 게스트 구분 관리

## 2. 사이트 이용 방법

**① 출석 체크**

클럽데이 날짜를 선택하고 참석한 회원을 출석 처리합니다. 게스트는 별도로 등록할 수 있습니다.

**② NTRP 설정**

회원 명단에서 실력 등급을 선택합니다. 게스트도 등록할 때 NTRP를 설정할 수 있습니다.

**③ 자동 대진 생성**

참석 인원과 경기 참여 횟수, NTRP를 고려하여 코트별 복식 대진을 생성합니다.

**④ 경기 결과 입력**

경기가 끝나면 승리팀을 선택하고 결과를 확정합니다. 코인 정산이 반영됩니다.

**⑤ 순위 확인**

시즌별 누적 코인과 회원 순위를 확인합니다.

## 4. 공동 이용 및 주의사항

본 사이트는 클럽원들이 편리하게 함께 이용할 수 있도록 로그인 절차를 최소화한 공동관리 시스템입니다.

- 출석과 경기 결과는 실제 진행 내용에 맞게 입력해 주세요.
- 경기 결과를 확정하기 전에 승리팀을 다시 확인해 주세요.
- 다른 회원이 입력 중인 기록을 임의로 변경하지 않도록 주의해 주세요.
- 코인 정산 오류가 발생하면 운영진에게 알려주세요.
- 회원별 NTRP는 실제 경기 수준을 고려하여 설정해 주세요.

**※ 현재 시스템은 시험 운영 중입니다.** 실시간 데이터 저장, 동시 수정, 기록 복구 등의 기능은 실제 사용 환경에서 검증 및 보완이 필요합니다.
