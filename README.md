# MTC 코인 리그 — 배포 가능한 웹사이트 초안

## 신규: 당일 자동 배정\n- 📅 오늘의 배정 탭에서 날짜별 참석자를 체크합니다. 늦게 온 회원도 즉시 추가하거나 퇴장시킬 수 있습니다.\n- 코트 수(1~8), 단식/복식을 선택하고 **자동 경기 배정**을 누릅니다. 출전 횟수가 적은 선수 우선, 복식 파트너 중복 최소화 방식으로 생성합니다.\n- 경기 종료 시 승리팀을 선택해 코인을 정산하고 다음 라운드를 생성합니다. 시즌 코인은 토요일마다 초기화되지 않습니다.\n- 현재 배정은 운영진 권한으로 생성합니다. 회원 자율 등록/결과 입력은 추가 보안 구현이 필요합니다.\n- 날짜별 출석은 별도 Firestore `attendance` 컬렉션에 기록합니다.\n\n## 포함 기능
- Google 로그인, 실시간 순위표(Firestore 구독), 반기별 시즌 전환
- 시즌 최초 3개 지급, 토요일마다 잔액 이월
- 코인 대출(보유·누적대출 동시 증가), 순보유=보유-누적대출
- 단식/복식 경기 생성, 결과 확정, 코인 이동, 출퇴장, 시즌 정산, CSV

## 중요: 현재는 운영진 입력형 베타 버전
이 패키지의 Firestore 보안 규칙은 **운영진만 변경**할 수 있도록 보수적으로 설정했습니다. 회원은 로그인 후 결과를 실시간으로 열람할 수 있지만, 직접 경기 결과를 입력할 수는 없습니다. 여러 회원이 직접 입력하는 버전은 서버 측 검증(Cloud Functions), 참가자 승인 및 권한 처리가 추가되어야 합니다. 프런트엔드 버튼이 표시되더라도 일반 회원의 쓰기는 보안 규칙에 의해 거부됩니다.

또한 현재 시즌 마감 버튼은 Firestore 규칙상 거부됩니다. 시즌 마감은 운영진이 Firebase 콘솔에서 시즌 문서의 `closed` 필드를 `true`로 변경해야 합니다. **실제 사용 전에는 경기 중복 확정 방지, 잘못 입력한 결과 정정, 이름 중복 방지, 관리자 권한 및 동시 입력 테스트를 수행하세요.**

## 1. Firebase 만들기
1. https://console.firebase.google.com 에서 프로젝트 생성
2. 프로젝트 설정 > 앱 추가 > 웹 앱 등록 후 설정값을 `firebase-config.js`에 입력
3. Authentication > Sign-in method > Google 활성화
4. Firestore Database 생성, 규칙 탭에 `firestore.rules` 내용 붙여넣기 및 게시
5. Firestore 데이터에서 `seasons` 컬렉션 > 문서 ID `2026-H2` 생성, 필드:
   - `adminEmails`: array, 운영진 Google 이메일 주소(문자열) 추가
   - `closed`: boolean, `false`
   - 다른 시즌을 사용하려면 해당 시즌 ID로 동일하게 문서 생성
6. Authentication > Settings > Authorized domains에 배포 도메인 추가

## 2. GitHub Pages 배포
1. GitHub 새 공개 또는 비공개 저장소를 만들고 `index.html`, `app.js`, `firebase-config.js`를 루트에 업로드합니다. (`firestore.rules`, `README.md`도 보관 가능)
2. Settings > Pages > Build and deployment > Deploy from a branch > `main` / root 선택
3. 몇 분 뒤 `https://사용자명.github.io/저장소명/`에서 접속합니다.
4. Firebase Authorized domains에 `사용자명.github.io`를 추가합니다.
5. 회원들에게 URL 또는 QR코드를 공유합니다.

## 운영 규칙 및 주의
- GitHub Pages는 프런트엔드만 호스팅하고, 실시간 데이터는 Firebase가 관리합니다.
- Firebase 웹 앱 설정값은 공개되어도 되지만 **서비스 계정 키나 비밀번호를 저장소에 올리지 마세요.**
- 이 패키지는 아직 상용 운영 검증을 마치지 않았습니다. 특히 Firestore 보안 규칙과 클라이언트 트랜잭션의 일관성을 배포 전 검증해야 합니다.
- 로그인한 회원 누구나 순위를 볼 수 있습니다. 외부인의 Google 로그인 자체를 막으려면 가입 승인/회원 허용 목록 검증을 추가하세요.
- Firestore 읽기/쓰기 사용량에 따라 Firebase 요금이 발생할 수 있습니다.

## v5 클럽 명단·게스트
- `club-roster.json`: 제공된 2026년 11월 명단에서 **이름과 활동/휴회/탈퇴 상태만** 추출한 54명. 연락처·회비·지역 정보는 포함하지 않습니다. 원본에서 이름 칸이 숫자 `32`로 기재된 1행은 제외했으므로 확인 후 별도 등록하세요.
- **회원 탭 → 클럽 명단 최초 불러오기**: 시즌에 회원이 없는 경우 운영진이 한 번 실행. 활동 34명은 시즌 최초 코인 3개, 휴회 16명과 탈퇴 4명은 비활성·코인 0개로 등록. 비활성 회원이 처음 출석하면 최초 3개 지급.
- **오늘의 배정 → 당일 게스트 바로 추가**: 이름 입력 즉시 게스트 등록·출석, 최초 코인 3개 지급. 동일 날짜 동일 이름 게스트 중복 등록 방지. 게스트는 일반 회원 시즌 랭킹에서 제외되지만 게임과 코인 기록에는 포함됩니다.
- 출석은 날짜별로 기록하고 코트 수는 2면으로 제한. 시즌 잔액은 토요일마다 이월.
- 게스트 3개 지급 및 시즌 종료 시 처리 방식은 운영 전 클럽 규칙에 맞게 확인하세요. 게스트도 코인이 부족하면 운영진이 대출할 수 있습니다.
- 운영진 권한으로만 명단 불러오기, 게스트 추가, 출석 변경, 대진 생성이 가능합니다.
- GitHub Pages/Firebase는 별도 설정이 필요하며, 실서비스 투입 전 Firebase 보안 규칙과 다중 기기 동시 작업 테스트를 권장합니다.
