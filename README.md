# 🎾 모두의테니스클럽 (MTC)

### MTC Tennis Club | 코인 리그 운영 시스템

모두의테니스클럽(MTC)은 경기도 파주시 법원읍에서 활동하는 테니스 동호회입니다.

본 사이트는 클럽원들이 함께 출석을 관리하고, 대진을 편성하며, 경기 결과와 코인을 투명하게 정산하기 위한 웹 기반 운영 시스템입니다.

**🌐 [MTC 코인 리그 사이트 바로가기](https://cojumkr.github.io/moduetennis/)**

---

## 📌 주요 기능

### 1. 회원 및 게스트 관리
- 클럽 회원 명단 및 활동 상태 관리
- 회원별 NTRP 실력 등급 설정
- 게스트 등록 및 NTRP 설정
- 회원·게스트 출석 및 퇴장 관리

### 2. 출석 및 출석 코인 관리
- 날짜별 출석 체크
- 실제 출석한 회원에게 출석 코인 **+1개 별도 지급**
- 출석 체크와 출석 코인 지급을 구분하여 관리
- 동일 날짜 중복 지급 방지
- 잘못 지급한 출석 코인 취소 가능

※ 출석 코인은 정해진 투표 대상자 중 실제 참석한 회원에게만 지급하는 것이 원칙이며, 투표 대상 여부는 운영자가 확인해야 합니다.

### 3. 자동 대진 및 수동 대진
- 코트 2면 기준 자동 복식 대진 생성
- 당일 경기 참여 횟수와 NTRP를 고려한 대진 편성
- 동일 파트너 및 상대 반복 최소화
- 수동으로 선수와 팀을 지정하여 대진 등록
- 과거 날짜의 경기 대진도 직접 등록 가능
- 단식 및 복식 경기 관리

### 4. 경기 결과 및 코인 정산
- 경기 승패 입력 및 코인 자동 정산
- 단식 승리 +1개 / 패배 -1개
- 복식 승리팀 각 +1개 / 패배팀 각 -1개
- 잘못 입력한 경기 결과 취소 및 코인 복구
- 날짜별 경기 및 정산 내역 조회

### 5. 반기별 코인 리그
- 상반기·하반기 시즌 운영
- 시즌 최초 참여 시 기본 코인 3개 지급
- 경기 및 출석 코인 누적 관리
- 코인 부족 시 클럽 대출 관리
- 보유 코인에서 누적 대출을 차감한 순위 산정
- 게스트 퇴장 시 잔여 코인 회수
- 회원별 코인 잔액 및 순위 확인

### 6. 데이터 보존 및 백업
- Firebase Firestore 기반 데이터 저장
- 회원 명단, NTRP, 출석 및 경기 기록 유지
- 사이트 기능 업데이트 시 기존 데이터 보존을 우선
- 전체 기록 JSON 백업 파일 다운로드
- Firebase 연결 완료 전 기록 저장 차단

※ 데이터 백업 및 보존 기능은 시험 운영 중이며, 중요한 기록은 별도로 백업하는 것을 권장합니다.

## 📱 사이트 이용 방법

**STEP 1. 날짜 선택**

클럽데이 또는 경기 진행 날짜를 선택합니다.

**STEP 2. 출석 체크**

참석한 회원을 선택하고 게스트가 있다면 추가합니다.

**STEP 3. 출석 코인 지급**

실제 출석 여부와 투표 대상 여부를 확인한 후 해당 회원에게 출석 코인 1개를 지급합니다.

**STEP 4. 대진 편성**

자동 대진을 생성하거나 현장에서 정한 대진을 수동으로 입력합니다.

**STEP 5. 경기 결과 입력**

승리팀을 선택하면 경기 결과와 코인이 정산됩니다.

**STEP 6. 기록 및 순위 확인**

날짜별 경기 기록과 정산 내역, 시즌 누적 코인 순위를 확인합니다.

## ⚠️ 공동관리 이용 수칙

본 사이트는 별도의 회원가입이나 로그인 화면 없이 클럽원들이 함께 사용할 수 있도록 구성되어 있습니다.

1. 실제 참석한 회원만 출석 처리해 주세요.
2. 출석 코인은 지급 조건을 확인한 후 입력해 주세요.
3. 경기 결과는 승리팀을 확인한 후 확정해 주세요.
4. 잘못 입력한 기록은 취소 기능을 이용해 주세요.
5. 다른 회원이 입력 중인 내용을 임의로 변경하지 않도록 주의해 주세요.
6. 중요한 기록은 정기적으로 백업해 주세요.

로그인 없이 수정할 수 있는 구조이므로 사이트 주소를 아는 외부인도 데이터를 변경할 위험이 있습니다.
